10 · 出场策略预注册

出场实验的范围、假设、变体、评估方法与失败判据。

状态：experiment-draft。 本文是实验协议，不是架构规范。§1 是当时的契约草案； 目标态契约以 specs/exit_contract.md 为准，执行语义以 design_spec.md 为准。实验参数一旦看结果前锁定，修改必须在文末 变更记录中写明并重跑。

状态：DRAFT，未看任何回测结果。所有参数在看结果前锁定；任何修改都要在文末变更记录中写明并重跑。

附录 A 是 2026-11-03 的审查快照，其中的行号可能已过期；以当前代码和 roadmap.md 为准。 依据：docs/strategy_principles.md 原则 1（动态边界、棘轮）、原则 5（验证门槛）。 日期：2026-11-03

0. 范围与非目标

范围：只评估出场规则。入场信号固定，不调优；仓位规则只做"按 R 定仓"这一条前提。

非目标： - 不设计新入场 alpha。 - 不调现有策略的参数（trend_following.py / hk_us_lead.py 暂不改）。 - 不引入行为数据（股东户数 / 资金流 / 龙虎榜尚无历史）。

1. 架构契约（C 作契约 + exits 作实现）

Strategy（纯 alpha）
   │  entry signal + ExitPlan（声明止损位、目标、棘轮、时间退出）
   ▼
仓位层：size = 风险预算 / R，R = entry_fill − initial_stop
   ▼
引擎：只执行订单类型 —— 市价 / 止损 / 止盈 / 移动止损 / 部分平仓
   │  盘中 low/high 触发 resting order；收盘决策下一 bar 执行
   ▼
Position（引擎独占，只读快照回喂策略）
   │  强制不变量：stop_price 非递减；R 入场时锁定；部分卖出不改 R 分母
   ▼
exits/：可复用的 ExitPlan 计算组件（ATR 止损、结构止损、棘轮、分批）

引擎不认识 ATR，也不认识"派发"；它只认订单类型。出场参数由策略在入场时声明，逻辑出场（阶段变化、背离）由策略发 SELL。

向后兼容：引擎默认"不挂单、只执行策略信号"，未迁移策略零改动可跑。

2. 执行假设（回测必须满足，否则结论无效）

项 规则
信号 收盘 D 产生 → D+1 开盘执行
resting stop/target 盘中触发：low ≤ stop → 成交价 min(open, stop)；high ≥ target → max(open, target)；跳空按开盘
A 股 T+1 当日买入不可当日卖出
涨跌停 开盘即封板且方向不利 → 本 bar 不成交，顺延；连续 3 bar 未成交 → 首个可成交开盘按市价出场并打标 forced_exit
成本 一律走 cost.TransactionCost；分批卖出每笔记最低佣金
滑点 A 股 5bp 单边；港股 10bp 单边（成本敏感性另测 0.5×/1×/2×）
污染行 沿用 engine._prepare_data 的 is_noisy 过滤
停牌 无成交，持仓延续

已知偏差（必须随结论一起披露）： - universe.py 剔除退市/ST → 买跌类入场存在幸存者偏差，结论偏乐观。 - 当前数据只有 OHLCV + amount + turnover_rate；逻辑出场只能用价格/量能代理。 - A 股无交易所止损单，实盘为券商条件单轮询；回测按"挂单即时触发"建模，实盘触发延迟未计入（paper trading 阶段验证）。

3. 语料（entry testbeds）

出场只能在固定入场上评估。预注册两组机械入场，结论按 archetype 分别成立，不合并：

  • E1 趋势：close > MA20 连续 3 日 ∧ MA10 > MA20 ∧ close > MA10；次日开盘入场。
  • E2 均值回归：patterns/second_lowest 的"中深破位 2–10%"事件（结构关系已跨窗口稳健）；回踩日收盘触发，次日开盘入场。
  • 两组均用 A 股主板，剔除 ST/退市（偏差见 §2）。港股作为第二阶段，不在本次主检验内。

4. 预注册假设

主假设（每个 archetype 各一条，共 2 条）

  • H1-trend / H1-mr：在相同入场上，ATR 结构止损 + 棘轮（V1） 的 OOS 单笔期望 R 高于 固定百分比止损止盈（V0），扣成本后成立。

次假设（探索性，单独标注，不用于"通过"判定）

  • H2：分批止盈（V2）相对 V1 提升盈利因子、降低 MFE 回吐，且扣除成本后仍为正。
  • H3：逻辑代理出场（V3：放量不涨 / 换手分位耗尽）在趋势 archetype 上叠加于 V1 仍有增量期望。
  • H4（机制自检）：按 R 定仓 + ATR 止损下，单笔最大亏损 ≤ 1.5R 的交易占比 ≥ 95%（含跳空）。

5. 预注册变体（参数锁定）

一进场一套参数，禁止在看结果后网格搜索再挑最优。若做敏感性扫描，必须报告完整网格 + 选择偏差，且不得作为主结论。

变体 止损 目标 棘轮 分批 时间退出
V0 现行基准 固定 −5% 固定 +15% 无 无 无
V1 主方案 max(结构20日低点−0.5ATR, 2.5×ATR14)；若距离 > 3.5ATR 则不入场 无固定目标 +1R 激活；max(保本, peak_close − 2.5×ATR14)，只上移 无 趋势无；均值回归 10 交易日
V2 分批 同 V1 无固定目标 同 V1 +2R 卖 1/3；余仓棘轮 同 V1
V3 逻辑代理 同 V1 无固定目标 同 V1 无 同 V1 + 放量不涨 / 换手分位耗尽

口径说明： - ATR14 = 14 日平均真实波幅（Wilder）。 - peak_close 用收盘更新；触发用盘中 low。 - 保本位在 +1R 达到后启用，且之后不再下移。 - 单笔风险预算 = 权益 0.5%；单票名义仓位上限 20%（组合层细调另议）。 - V0 的 ±5%/+15% 取自现有 trend_following DEFAULT，作为"现行做法"对照，不代表它是最优。

6. 评估方法

  1. 配对实验：V0–V3 使用完全相同的入场事件、日期、成本假设，只有出场不同。
  2. R 口径：单笔实现盈亏 ÷ 入场时 R 金额；部分平仓合并计算。
  3. Walk-forward：参数已锁定，不做拟合；按 6 个月滚动块报告 OOS，不设训练窗调参。
  4. 聚类统计：按 symbol 与 (date, theme/cap bucket) 聚类做 block bootstrap；同题材料同一天只算一个 bet。
  5. 报告指标（全部报告，不挑选）：平均 R、盈利因子、胜率、最大单笔亏损（R）、MAE/MFE 分布、最大回撤、换手、成本占毛利、持仓天数、退出原因分布。
  6. 绝对与相对并报：不只报"相对 V0 的超额"，也报绝对期望 R。
  7. 时间切分：至少 <2022 / ≥2022 分段；逐年表全部列出。
  8. 多重比较：主假设 2 条按 Holm 校正；次假设只做探索性描述。

7. 失败判据（预先锁定，任一触发即不通过）

主假设判定：

  • 通过需同时满足：OOS 平均 R 差 > 0；block bootstrap 95% CI 下界 > 0；≥70% 的 walk-forward 窗口方向为正；最大贡献年份/regime 占增量盈亏 ≤ 50%；扣成本成立。
  • 失败：CI 含 0；或多数窗口符号翻转；或增量盈亏集中单一 regime；或样本不足。
  • 不可判定：多数测试窗口 n < 30。不可判定 ≠ 通过。
  • 机制否决（独立于收益）：H4 不满足（单笔亏损 > 1.5R 占比 > 5%）→ 该变体不得上 paper。
