01 · 项目入口

项目简介、快速开始与文档入口。

A股 / 港股量化交易系统：数据管道、策略、回测、组合与成本模型。

状态：研究/开发阶段。当前代码是过渡期实现，目标架构见 docs/architecture.md；两者不一致时，以 docs/design_spec.md 和已接受的 ADR 为准。

本系统尚未通过 paper trading 门槛，不用于实盘。

最新进展（2026-11-04）：独立出场模拟器完成 bug-fix pass； 356 passed, 1 skipped。演示 watchlist 的样本内结果见 docs/experiments/exit_sensitivity_2026_11.md ——不是策略验证通过，正式测试仍需真实 watchlist 与 walk-forward/OOS。

快速开始

# 测试
python -m pytest -v

# 数据
python -m datafeeder.cli download --symbols 000001.SZ
python -m datafeeder.cli query --symbol 000001.SZ --latest 60

# 成本
python scripts/trade_cost.py --market a --mode roundtrip --price 100 --shares 1000

# 回测（当前过渡引擎）
python -m backtest.engine

# 出场-only 实验（watchlist 在 config/exit/base.yaml）
python scripts/exit_experiment.py \
  --config config/experiments/exit_sensitivity_2026_11.yaml

安全与边界

  • 所有费用/税计算必须走 cost.TransactionCost；费率唯一源是 config/fee_config.yaml。
  • Token 只放在 config/tokens.yaml 或环境变量，不进入 tracked YAML。
  • 当前支持 long-only；不做空、不接科创板。
  • 实盘前必须完成 paper trading 3–6 个月，并通过执行现实性与对账检查。
