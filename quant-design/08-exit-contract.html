08 · 出场契约

ExitPlan、棘轮不变量、分批、时间退出与必需测试。

本文定义目标态的 ExitPlan 与执行语义。当前代码尚未实现；实现状态见 ../roadmap.md。实验协议见 ../exit_preregistration.md；两者冲突时，本文是规范， prereg 是实验假设。

1. 关系与范围

  • 本文规范：ExitPlan 字段、棘轮不变量、分批/时间退出、与订单类型的映射。
  • 执行现实性（D+1、盘中触发、T+1、涨跌停、费用）以 ../design_spec.md#7-执行语义 为准。
  • 本文不规定具体 ATR 倍数、目标 R 或参数值；那些属于策略/预注册。

2. ExitPlan 字段

入场时由策略声明，随 Intent 传给执行层：

字段 类型 必填 语义
initial_stop price 是 初始止损价；多头必须 < entry_fill
risk_per_share price 是 entry_fill - initial_stop，即 1R；入场后锁定
targets list[(price, fraction)] 否 目标价与卖出比例；fraction 之和 ≤ 1
partials list[(r_multiple, fraction)] 否 按 R 分批；与 targets 二选一优先
trail_activate_r float 否 浮盈达到多少 R 后激活棘轮
trail_atr_mult float 否 棘轮宽度 = k × ATR；策略换算成具体 stop price
trail_giveback_ratio float 否 从峰值最多回吐的比例（可选，与 ATR 取宽）
breakeven_after_r float 否 达到多少 R 后止损至少上移到 entry
time_exit_days int 否 持有 N 个交易日后退出
force_exit_after_unfilled int 否 涨跌停/停牌连续 N bar 未成交后强制退出并打标

规则：

  • 执行层只接收具体价格/数量；trail_atr_mult 等由策略在每根 bar 收盘后换算成新的 stop_price，以 Intent（SET_STOP/SELL）表达。
  • 一个持仓同一时间只能有一个 active ExitPlan；更新是替换，不是叠加。
  • 部分退出后，ExitPlan 的 R 分母不变；剩余部分继续使用同一计划（可按需要更新 targets，但必须记录）。

3. 不变量

  1. initial_stop < entry_fill（多头）。
  2. risk_per_share = entry_fill - initial_stop > 0，入场后不变。
  3. stop_price 非递减；任何更新只能上移。
  4. sum(partial.fraction) <= 1.0；qty_sold + qty_remaining == qty_initial。
  5. 部分卖出的已实现 PnL 按成交价与成本计算，不改变剩余仓位的 risk_per_share。
  6. 同一 bar 同时触止损/止盈，默认止损优先（保守），并记录 tie-break。
  7. 跳空穿越 stop：成交价 min(open, stop)；实际亏损可 > 1R，必须记录。
  8. 涨跌停/停牌不可成交时，订单保留/过期/forced_exit 必须显式，不得静默跳过。

4. 与订单类型的映射

ExitPlan 规则 执行层订单
初始止损 resting STOP（卖出）
固定目标 resting LIMIT/TAKE_PROFIT（卖出）
移动止损 策略更新 stop_price → 修改/替换 STOP
分批目标 多个 LIMIT/TAKE_PROFIT，数量为 fraction × qty
按 R 分批 策略在达到 R 时发 SELL Intent.qty；执行层不计算 R
时间退出 到期日收盘决策，下一 bar 开盘市价卖出
逻辑退出（阶段/背离） 策略发 SELL Intent，可全平或部分

执行层必须支持：提交、修改、取消、部分成交、拒单、过期。订单状态只能由 OrderManager 修改。

5. 分批退出

  • 批次数量必须是 lot size 的整数倍；不足一手的剩余按规则处理（A 股卖出可含零股）。
  • 每批独立计费（最低佣金/印花税/滑点）；报告必须给 net R，不只 gross。
  • 批次优先级：先触发的先执行；同一 bar 多批触发时按价格/规则排序，并在回测中记录。
  • 分批不应改变 R 分母；绩效归因按初始 R 计算整笔交易。
  • 若分批的增量期望 R 小于增量成本，不应分批；该判断属于策略/实验，不是执行层。

6. 时间退出

  • time_exit_days 按交易日计，不按自然日。
  • 到期决策在收盘产生，下一 bar 开盘执行（与 D+1 一致）。
  • 到期前已触发止损/目标则按已触发规则。
  • 时间退出是独立退出原因，报告中单列。

7. 强制退出

触发条件（示例）：

  • 连续 N bar 因涨跌停/停牌无法成交；
  • 数据污染/标的不再可交易；
  • 风控强制平仓。

规则：

  • 首个可成交 bar 按市价/可成交价退出；
  • 打标 forced_exit，记录原因和延迟 bar 数；
  • 不得假设按 stop/target 价格成交；
  • 报告必须把 forced_exit 与正常止损分开统计。

8. 与当前实现的差距

生产路径当前：

  • Signal 无 ExitPlan/数量/订单类型；
  • SELL 永远全平；
  • 无 resting stop/target；
  • 同 bar 收盘成交；
  • 无 T+1/涨跌停；
  • Position 无 initial_stop/risk_per_share/peak。

Track A 研究模拟器（backtest/exit_sim.py）已实现本文的出场语义：D+1、盘中 high/low 触发、跳空按 open、T+1、涨跌停、分批、逐笔费用、棘轮只上移、R 分母锁定。 它只用于单笔事件研究，不是生产执行路径；结果不能直接当作 engine 能力。

迁移：阶段 4 实现生产执行现实性；阶段 6 策略迁移到 Intent/ExitPlan。在迁移 完成前，单笔出场实验应使用 simulate_exit()，并遵守本文语义，避免结论不可迁移。

9. 必需测试

  1. 跳空穿越止损：fill = min(open, stop)，R < -1。
  2. 同日止损/止盈：止损优先。
  3. 棘轮只上移：价格回落后 stop 不下移。
  4. 部分卖出：qty_remaining + qty_sold == qty_initial；R 分母不变；费用逐笔。
  5. A 股 T+1：买入当日卖出被拒绝。
  6. 涨跌停：方向不利封板不成交；连续 N bar 后 forced_exit。
  7. 时间退出：按交易日，D 收盘决策/D+1 开盘执行。
  8. 费用：每笔 fill 的 amount == shares × price；费用可加总。
  9. 确定性：相同输入/配置/种子 → 相同 fills。
